Markdown Content Showcase: From Headings to Media

A ready-to-preview article template demonstrating heading levels, text formatting, lists, tables, code, and media.

MarkdownWriting guideExample

This is a ready-to-use Markdown article example. Use it to see how content appears on the site, then copy, edit, and replace it with your own. The headings, descriptions, and media URLs below are demonstration material.

Make the content clear first, then choose its formatting. Good formatting helps readers understand; it does not replace the content.

Article structure

Use heading levels to organize topics. Start each section with an introduction, then add more specific subsections when needed.

A subsection under a topic

This is a regular paragraph. Use paragraphs to introduce background, explain an idea, or preview what comes next. Leave a blank line between paragraphs.

A more specific section

Headings can be nested further. Use heading levels in order rather than skipping levels just to change the font size.

Inline text formatting

The body supports bold, italic, strikethrough, inline code, and regular links. Use these to highlight terms, command names, or references.

Lists and quotes

Unordered list

  • First item: list a point or material.
  • Second item: an item can be a complete sentence.
  • Third item: indent two spaces for nested items:
    • Sub-item A
    • Sub-item B

Ordered list

  1. Identify the problem to solve.
  2. Explain the process step by step.
  3. Summarize the result or what to do next.

Task list

  • Add a title and summary
  • Create the article structure
  • Replace the sample with your own content

Markdownコンテンツ例：見出しからメディアまで

見出し、文字装飾、リスト、表、コード、メディアなど、記事テンプレートで使える書式を紹介します。

Markdown文章作成サンプル

これはそのままプレビューできるMarkdown記事のサンプルです。サイト上での表示を確認し、コピーして自分の記事に合わせて編集できます。見出しや説明、メディアのURLはすべて例です。

まず内容をわかりやすく書き、そのあとで書式を選びましょう。適切なレイアウトは理解を助けますが、内容そのものの代わりにはなりません。

記事の構成

見出しのレベルを使ってテーマを整理できます。各セクションに導入を書き、必要に応じて小見出しで詳しく説明しましょう。

テーマの下にある小見出し

これは通常の段落です。背景を紹介したり、考えを説明したり、次に扱う内容を示したりできます。段落の間には空行を入れます。

さらに詳しい小節

見出しはさらに細分化できます。文字サイズを変えるためにレベルを飛ばさず、順番に使いましょう。

インラインの文字装飾

本文では太字、斜体、取り消し線、インラインコード、通常のリンクを使えます。キーワードやコマンド、参考資料を示すのに便利です。

リストと引用

箇条書き

  • 1つ目：要点や材料を列挙します。
  • 2つ目：各項目を文章にしても構いません。
  • 3つ目：2つのスペースでインデントすると、入れ子にできます。
    • サブ項目 A
    • サブ項目 B

番号付きリスト

  1. 解決したい問題を決めます。
  2. 手順を順番に説明します。
  3. 結果や次の行動をまとめます。

タスクリスト

  • タイトルと概要を用意
  • 記事の構成を作成
  • 自分の内容に置き換える

表

短く比較できる情報には表が便利です。

コンテンツ用途例
段落紹介と説明背景
リスト関連する項目準備
コード技術的な例設定

コード

npm run build のようなコマンドはインラインコードで示せます。コードブロックには言語名を付けると、シンタックスハイライトが使われます。

type Article = {
  title: string;
  published: boolean;
};

const example: Article = {
  title: "Markdownコンテンツ例",
  published: true,
};

console.log(example.title);

Shellなど、ほかの言語も指定できます。

npm install
npm run dev

画像とメディア

画像

Markdown記法で画像を挿入できます。次の例ではサイト内のアバターを使っています。自分の記事では public/ 内の画像に置き換えてください。

サイズやCSSクラスを指定する場合はHTMLも使えます。

音声

音声にはHTMLの <audio> 要素を使います。公開する際は、利用許可のある音声ファイルに置き換えてください。

動画ファイル

<video> で動画を再生できます。src はローカルのメディアパス、またはアクセス可能な動画URLに置き換えてください。

埋め込み動画

動画サービスによってはiframeの埋め込みコードが提供されています。次の例はYouTubeのプライバシー強化モードです。公開前に動画IDを置き換え、埋め込みが許可されているか確認してください。

補足

折りたたみ表示は補足説明に便利です。必要なければ削除できます。

クリックして補足を表示

用語の説明や追加のヒントなど、本文の流れに影響しない内容を記載できます。

まとめ

記事には導入、複数レベルの見出し、メディア、まとめを組み合わせられます。すべての要素を使う必要はありません。内容に合った書式を選び、このサンプルの文章、画像、メディアURLを忘れずに置き換えてください。

Markdown 内容示例：从标题到多媒体

这是一篇可直接预览的文章模板示例，展示常见标题层级、文字格式、列表、表格、代码和多媒体内容。

Markdown写作指南示例

这是一篇可直接使用的 Markdown 示例文档。你可以从中了解文章在网站上的呈现方式，再复制、删改并替换成自己的内容。文中的标题、说明和媒体地址都是演示素材。

写作时先把内容讲清楚，再考虑格式。合适的排版能帮助读者理解，而不是取代内容本身。

文章结构

文章可以用不同层级的标题划分主题。每个标题下面都可以先写一段介绍，再继续细分内容。

二级主题下的子标题

这是一个普通段落。这里可以介绍背景、解释概念，或用几句话说明接下来要讨论什么。段落之间留一个空行即可。

更深一层的小节

标题层级可以继续细分。建议按顺序使用标题，不要为了字号跳过层级。

行内文字格式

正文支持粗体、斜体、删除线、行内代码和普通链接。这些格式适合标出关键词、程序名称或相关资料。

列表与引用

无序列表

  • 第一项：列出要点或材料。
  • 第二项：每一项可以写成完整句子。
  • 第三项：需要嵌套时缩进两个空格：
    • 子项目 A
    • 子项目 B

有序列表

  1. 先确定要解决的问题。
  2. 再按步骤说明过程。
  3. 最后总结结果或下一步行动。

任务清单

  • 写好标题和简介
  • 添加正文结构
  • 替换成自己的真实内容

内容类型适用场景示例
段落介绍和解释背景说明
列表并列要点准备材料
代码技术示例配置片段

Markdown 콘텐츠 예제: 제목부터 미디어까지

제목 단계, 텍스트 서식, 목록, 표, 코드와 미디어 등 글 템플릿에서 사용할 수 있는 형식을 소개합니다.

Markdown글쓰기 가이드예제

이 글은 바로 미리 볼 수 있는 Markdown 예제 문서입니다. 사이트에서 콘텐츠가 어떻게 보이는지 확인한 다음 복사하고 수정해 자신의 글로 바꿔 보세요. 제목과 설명, 미디어 주소는 모두 예시입니다.

먼저 내용을 명확하게 쓴 뒤 형식을 고르세요. 알맞은 서식은 이해를 돕지만 내용 자체를 대신하지는 않습니다.

글의 구성

제목 단계를 사용해 주제를 나눌 수 있습니다. 각 섹션에서 먼저 간단히 소개하고 필요한 경우 하위 제목으로 더 자세히 설명하세요.

주제 아래의 하위 제목

일반 문단입니다. 배경을 소개하거나 개념을 설명하고, 이어질 내용을 간단히 안내할 수 있습니다. 문단 사이에는 빈 줄을 둡니다.

더 세부적인 소제목

제목은 여러 단계로 나눌 수 있습니다. 글자 크기를 바꾸기 위해 단계를 건너뛰지 말고 순서대로 사용하세요.

인라인 텍스트 서식

본문에서는 굵게, 기울임, 취소선, 인라인 코드, 일반 링크를 사용할 수 있습니다. 키워드나 명령어, 참고 자료를 표시할 때 유용합니다.

목록과 인용

글머리 기호 목록

  • 첫 번째 항목: 요점이나 자료를 나열합니다.
  • 두 번째 항목: 각 항목을 완전한 문장으로 써도 됩니다.
  • 세 번째 항목: 두 칸 들여쓰기로 중첩 목록을 만들 수 있습니다.
    • 하위 항목 A
    • 하위 항목 B

번호 목록

  1. 해결할 문제를 정합니다.
  2. 과정을 순서대로 설명합니다.
  3. 결과나 다음 행동을 정리합니다.

작업 목록

  • 제목과 요약 작성
